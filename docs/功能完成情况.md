# v0.2 主要功能完成情况

## 前端

- 完成 7 个页面：此刻、橱窗、收藏、商品详情、设置、火花币、历史情境。
- 整体采用浅米色、灰绿和原创烟盒构图；第一人称页使用深色沉浸场景。
- 公司厕所/阳台通过 Canvas 绘制，支持日间、黄昏、夜间。
- 双手、打火机、烟支、点火、长按、松手烟雾、烟灰、抖灰、自然燃烧和结束状态。
- 合成操作音效、震动、画质档位和偏好保存。
- 页面加载、错误重试、库存不足、免费款自动回退、领取状态、空记录和分页。
- 开局和兑换请求编号落盘；切后台停止循环，保存进度，返回不重抽事件。
- 橱窗到详情、兑换到收藏、选用到体验、结束到历史的完整链路。

## 后端

- PostgreSQL 数据层：本地 PGlite 自动初始化并落盘；独立数据库使用 pg 连接池。
- 事务仓储通过 SELECT FOR UPDATE 锁定同一玩家，金额变化和独立账本原子提交。
- guest 开发登录，微信 code2Session 登录适配，随机访问令牌、哈希存储与续期。
- 初始化、兑换、库存、开始/结束/进度、每日补给、偏好同步、分页历史和钱包记录。
- DTO 严格校验、错误码、账号隔离、幂等操作、进度乱序防护。
- 生产配置要求独立 PostgreSQL 与微信登录，迁移可显式执行。

## 不属于本轮已验证成果的内容

- 没有接触真实微信 AppID/AppSecret，实际授权待配置验证。
- 没有通过微信专用编译器和真机运行；浏览器预览是实际模板的视觉转换，不是微信运行时。
- 自动数据库测试使用 PGlite，未启动独立 PostgreSQL 或验证生产 TLS。
- 手部为原创程序化插画风，不是写实人物素材或三维模型；性能目标尚未真机测量。
- 没有制作事件管理后台。运营内容暂维护在 packages/domain/src/catalog.ts。
- 未部署、提审或创建 Git 提交。
