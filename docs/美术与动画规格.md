# 第一人称美术与动画

## 当前实现

apps/miniprogram/src/rendering/scene.ts 是原创程序化插画渲染器：

- 公司厕所：隔间墙面、门缝、门锁、纸卷、环境明暗。
- 阳台：天空、远处楼群和窗灯、栏杆、盆栽、道具接触面。
- 双手：皮肤渐变、连续轮廓、手指细节和独立衣袖。
- 打火机、烟支、烟头、烟灰、烟雾，以及动作变换。
- ready、lighting、burning、inhaling、ashing、extinguishing 状态。
- 画面按设备尺寸缩放；提供 high/standard 两档绘制频率与烟雾数量。
- 3 段操作音效由 scripts/generate-audio.mjs 确定性合成，没有使用第三方录音。

当前风格是插画式，不是写实人物图像或三维模型。以它作为主要功能版本的可用视觉基础。

## 当前层次

后到前：场景背景、场景前景、左右手与道具、燃烧/烟灰、烟雾、界面。主画面固定第一人称，左手打火机，右手持烟，中央留出视野。

抬手到嘴边时右手部分移出视野；松开后烟雾从画面下方上升。前台自然燃烧，切后台停止计时与动画，保存进度。每轮事件只生成一次。

## 后续可选美术升级

如需要更写实的风格，可以替换为分层手部贴图/序列帧，保留现有领域业务和接口。资源必须原创或合法授权，不复制参考小程序。

每套场景应维护：远景、前景遮挡、三档时段调色、左右手初始锚点、点火位置、抖灰和熄灭位置。使用归一化坐标，避免不同场景直接套同一桌面。
