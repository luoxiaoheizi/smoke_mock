## 维护方式

- 商品名称、基础信息、包装路径、游戏价格统一在 `packages/domain/src/catalog.ts` 中配置，API 和前端演示模式共用。
- 替换图片时同步更新来源清单与 SHA-256。`npm run check` 会验证图片存在、打包前后相同、来源与哈希匹配。
- 商店、商品详情、收藏使用原生 image，并以 aspectFit 展示完整包装。图片失败后显示名称占位，购买操作仍可使用。
- 保留原有三款原创外观、商品 ID 和玩家存档。首次默认仍为免费“留白”，新增品牌款需使用虚拟余额购买。
- 本次更新商店包装与信息；体验中的烟支仍使用现有场景绘制与对应色彩，不新增写实品牌烟支模型。
